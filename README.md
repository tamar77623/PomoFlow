⏱️ PomoFlow - Smart Pomodoro & Focus Timer

PomoFlow is an intuitive, distraction-free Pomodoro timer designed to help users maintain deep focus and optimize productivity through seamless work-rest cycles.

Unlike standard timers, PomoFlow introduces a Smart Auto-Trigger feature: if left idle for 5 seconds after a state reset or cycle completion, the timer automatically initiates the next focus block. This prevents momentum loss and ensures continuous productivity even if you forget to manually click start.

Built purely with vanilla web technologies, this project prioritizes performance, zero dependencies, and fluid DOM interaction.

✨ Key Features

🎯 Smart Auto-Trigger (Auto-Click): Automatically starts the session after 5 seconds of inactivity to keep your focus flow uninterrupted.

⌛ Customizable Cycles: Dedicated work, short break, and long break intervals.

🔔 Visual & Audio Cues: Clear UI indicator changes and sound alerts upon cycle completion.

⚡ Ultra-Lightweight: 100% Vanilla JS—zero external frameworks, ensuring instant load times.

📱 Fully Responsive UI: Clean, modern layout crafted with HTML and CSS for mobile and desktop screens.

🛠️ Tech Stack

Frontend: HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)

Deployment: GitHub Pages / Vercel
